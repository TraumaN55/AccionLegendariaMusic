# AccionLegendariaMusic

Pack de música de AccionLegendaria para TaleSpire.

Este repositorio no contiene directamente el ZIP de música.
El pack se distribuye mediante GitHub Releases y se instala automáticamente desde AccionLegendaria Launcher.

## Pack activo

- Bundle ID: `63ec575d-d713-42b6-a61d-01c03338a1df`
- Ruta de instalación: `TaleSpire/Taleweaver/63ec575d-d713-42b6-a61d-01c03338a1df`

## Actualización

Para actualizar la música:

1. Generar un nuevo pack en Creadth usando el mismo Bundle ID.
2. Subir el ZIP como asset de una nueva GitHub Release.
3. Actualizar `music-manifest.json` con la nueva versión y URL.
